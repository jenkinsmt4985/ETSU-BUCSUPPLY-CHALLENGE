BucSupply V7.1 real-photo folder

Before uploading the game to GitHub, double-click SETUP_REAL_PHOTOS.bat
or run SETUP_REAL_PHOTOS.ps1 from PowerShell.

That script downloads the verified CC0/public-domain supply-chain photographs
into this folder. Once downloaded, normal gameplay uses the local image files.

If the local images are missing, the HTML has verified Wikimedia Commons
fallback URLs so the page will still display the real photographs while online.
